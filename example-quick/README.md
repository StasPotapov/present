# Пример: короткий путь

Дека из 6 слайдов о самом коротком пути `/present`, собранная по `stages/quick.md`. Короткий путь отдаёт ровно один файл — вот он:

```bash
open present-korotkiy-put.html
```

Файл открывается офлайн и весит 77 КБ: в нём движок, стили и слайды. Листать — `←` `→`, колесо, свайп. `B` — чёрный экран, `F` — fullscreen, `S` — PDF. `?check` в адресе подсвечивает переполнения.

Окна докладчика нет: на `<html>` стоит `data-presenter="off"`, клавиша `P` ничего не открывает, заметок в деке нет. Так короткий путь работает по умолчанию. В конце скилл одной строкой предлагает добавить окно с заметками.

## Каким запросом собрана

```
/present Сделай простую презентацию на 6 слайдов: что такое короткий путь скилла present.
Когда его брать, что получается на диске, какие шаги проходит скилл, почему нет окна
докладчика и как раскрутить такую деку до доклада.
```

На таком запросе скилл задаёт два вопроса: путь (короткий) и куда положить файл. Затем он собирает деку и проверяет её: валидатор, `?check`, аудитор макета, кадры в Chrome, headless-печать PDF. Эта дека прошла все пять проверок.

## Чем отличается от `../example/`

| | `example-quick/` | `example/` |
|---|---|---|
| Путь | короткий | полный |
| Файлы | один `.html` | рабочая папка: `slides.md`, `design.md`, `DECK.md`, `build.py`, `src/`, `deck/` |
| Окно докладчика | нет | есть, с живыми заметками |
| Статус конвейера | не ведётся | раздел «Конвейер» в `DECK.md` |

Этот `README.md` — документация репозитория. Сам скилл на коротком пути рядом с декой ничего не кладёт.

Текст слайдов написан для этого репозитория и покрыт лицензией MIT вместе со скиллом.
