## Режим деки: «скрипт»

В папке лежит `build.py` и его исходники в `src/`. **Правь исходники и пересобирай**, готовый HTML руками не трогай:

```bash
python3 build.py          # пересобрать деку в deck/ (notes.js не трогается, если он уже есть)
python3 build.py --notes   # пересобрать И перезаписать notes.js из data-notes
```

Исходники:

| файл | что это |
|---|---|
| `src/design.css` | весь беспоук-CSS деки (уезжает в `<style id="design">`) |
| `src/slides.html` | 17 секций слайдов с `data-notes` (уезжает в `#deck`) |
| `src/inter-faces.css` | 4 блока `@font-face` Inter в base64 (roman/italic × cyrillic/latin), 280 КБ |
| `src/kernel-v5.html` | копия движка из ассетов скилла — фолбэк, если скилл переехал |

Картинки в `src/slides.html` помечены маркером `IMG:имя-файла` (в двойных подчёркиваниях);
`build.py` подставляет вместо них inline data-URI из JPG в корне папки.

## Арт-дирекшн (сжато)

- **Настроение:** тёплая кремовая бумага с одним ядовито-розовым маркером (бриф Playful).
- **Палитра:** `--canvas #f6f2ee` · `--paper #fff` · `--ink #111` · `--magenta #ff2e95` ·
  `--stone #848383` · `--sand #e2dcd6`. Магента — единственный хроматический голос.
- **Типографика:** Inter вшит base64 (variable 100–900, прямой + курсив, cyrillic+latin).
  Заголовки — 900/700 **italic**, `line-height` 1.0–1.04, tracking −0.002em (как в брифе).
- **Фон `#bg`:** два мягких радиальных градиента (розовый отсвет справа сверху, песочный слева снизу)
  + SVG-зернистость 4.5% как «бумага». Не анимирован.
- **Движение:** мягкое — `pop`/`rise` на карточках и тегах, `.chain` на 05, пульс кнопки записи на 12,
  печать на 17. Ни pipeline, ни глитча, ни scanlines — не в характере бренда.
- **MOTION LAYER v2** (в конце `src/design.css`, пришёл из Claude Design): единая партитура входа —
  лента → заголовок → лид → сноска, каскад по `nth-child` внутри рядов-схем, розовый маркер
  «дочерчивается» под акцентными словами (`h1 .mg,h2 .mg`), петли прочерчиваются сверху вниз,
  фоновый розовый орб дышит 34 с, блик по `/present <папка>`, клавиша `P` нажимается сама,
  карточка QR подмигивает, галерея 09 лежит веером (`--rot` на figure).
  Всё на ключевых кадрах, без статического `opacity:0` — поэтому печать в PDF видит финальные состояния.

## Принятые решения и отступления

- **Шрифт вшит, а не системный** (согласовано): подпись стиля — тяжёлый курсивный Inter, системный SF
  ломал бы характер. 4 subset-файла, ~280 КБ base64 внутри HTML. Дека остаётся офлайн-автономной.
- **Радиусы:** 44px у крупных карточек (как в брифе), 28px у компактных узлов схем — 44px на узле
  высотой 70px превращает его в капсулу и ломает читаемость. Это осознанное отступление.
- **Счётчиков `.count` в деке нет:** в докладе нет статистики, накручивать «0 CDN» бессмысленно.
- **Иконки — только inline SVG-штрихи в Stone**, эмодзи убраны: Do/Don't брифа прямо запрещает
  залитые цветом пиктограммы.
- **`.loopline` (петли на 03/11/15) лежит ВНУТРИ своего ряда** (`.stages` / `.cycrow`, у них
  `position:relative`, петля — `top:100%`). Если вынести её обратно на уровень `.map`/`.cyc`,
  левый конец уедет под соседние блоки и стрелка укажет не туда.
- **`.loopline.hot` / `.thin` задают `border-width` в три значения** (`0 3px 3px`): короткая запись
  вернула бы верхнюю границу и нарисовала лишнюю линию по нижней кромке карточек.
- **`.branch{align-items:flex-start}`** — при `stretch` колонка с петлёй растягивалась по высоте
  соседней карточки, и петля улетала вниз на пол-экрана.
- **Моторный слой принят из Claude Design как есть**, с одной правкой: анимация `washin` на слайде 06
  стартовала с `translateY(7%) scale(1.08)` и уводила абсолютный `::before` на 53px за нижнюю кромку —
  `?check` честно ловил переполнение на всех разрешениях. Заменено на рост от нижней кромки
  (`transform-origin:50% 100%` + `scale(1.1)` без сдвига): эффект тот же, лишней высоты нет.
  `overflow:hidden` на слайде эту проблему НЕ лечит — `scrollHeight` всё равно считает overflow-контент.
- Известные ловушки: `backdrop-filter` не использовать (конфликт со `slidefade`); на слайде 06
  розовый wash сделан через `.slide.wash::before` с `z-index:-1` — не менять на `filter`.
  Каскадное правило `:is(.stages,.inflows,…)>*` цепляет и `.loopline`, и `.card` внутри `.split` —
  их персональные правила обязаны идти в файле ПОСЛЕ каскадного блока, иначе перебьются.
- В kernel ничего не правилось (`WHEEL_TH`/`WHEEL_COOLDOWN` — дефолтные).

## Как править

- РЕЖИМ — «скрипт»: правь `src/*`, потом `python3 build.py`. Готовый HTML руками не трогать.
- Пришли правки из Claude Design → забирай `src/design.css` и `src/slides.html` через `DesignSync get_file`
  (сам HTML не читается — см. предупреждение вверху), клади в `src/`, пересобирай и прогоняй `?check`:
  моторные правки легко дают переполнение через transform в стартовом кадре.
- Текст/структура слайдов → `src/slides.html` (секции идут по порядку, у каждой комментарий `NN ─ заголовок`).
- Стили → только `src/design.css`; `<script id="kernel">`, `<style id="print">` и chrome-DOM (`#bar/#counter/#hint`) не трогать.
- Заметки спикера → `slova-vid-golos-2026-07-28-notes.js` — **источник правды** после первой сборки:
  их правят прямо в окне докладчика («✎ править» / двойной клик, «☰ все заметки») и выгружают кнопкой
  «⤓ notes.js» рядом с декой. `data-notes` в `src/slides.html` — fallback-копия.
  **Перед `--notes` обязательно перенеси актуальный текст из `notes.js` в `data-notes`**, иначе правки с репетиции затрутся.
- Медиа: три JPG вшиты base64 при сборке, sidecar-папки нет — деку можно пересылать одним файлом.
- Проверка после правок:
  `python3 ~/.claude/skills/present/assets/validate.py slova-vid-golos-2026-07-28.html`
  плюс открыть деку с `?check` в адресе (kernel подсветит переполненные слайды).
